Baseline text Qs: F1 0.30 when gold found vs 0.17 when missed (both 7B and 14B; oracle context only 0.195). Recall 48%->73% on text Qs predicts F1 ~0.232->0.265 = +0.03, while n=20 gives CI half-width ~0.1. So T2 cannot detect the F1 gain; judge the fix by MECHANISM (gold_found rate, F1 hit-vs-miss) not by headline F1. Raising max tokens is the wrong lever: RAG has no search budget; the agent budget only caps extra retrieval steps (answer call always runs); answer cap 192 shows no truncation in saved preds.
CUT: dependency order metric -> retrieval/generation mechanism -> agent budget -> contingency actions ranked by cost. Prediction (is the fix working?) separated from decision (what to change).

RULES (T2/T3 outcomes -> action)
- A) gold_found >=60% and F1_hit > F1_miss, F1 flat/up: fix works, F1 gain just below noise. Start Phase 3 as configured.
- B) F1_hit ~ F1_miss (gold present but not used): reader/metric problem. Hand-label the 20 rows; if most hit rows are correct, the ruler is the issue -> get the judge go before reporting finance numbers; if wrong, it is 7B capability -> 14B is the reader, router decides. No retrieval changes.
- C) gold_found in T2 < ~60% although T1 said 73%: bug in wiring (config not applied, agent/RAG path) -> fix, rerun T1/T2. Check Retriever.from_config usage.
- D) F1 DROPS vs baseline and misses fell: context noise from top_k 8. Run scope@5 vs scope@8 comparison on same 20 Qs (one extra 10-min run) and choose by hit/miss F1 + tokens; do not guess.
- E) T3: 9000 cuts max_tokens stops <10% AND F1 up -> adopt 9000; else keep 6000, agent = measured negative arm. Do not build corrective-RAG unless retry shows a hit-rate gain.
- F) Recall residual: if the 15-27 remaining misses are mostly "right filing wrong window" -> try neighbour expansion (no install). Hybrid/rerank only if recall < 70% on the larger Phase 3 slice (needs Arnav's yes).
- G) Never: raise max_answer_tokens/max_tokens as a general fix (no truncation seen; RAG unaffected), tune on the T2/T3 slice, rerun Phase 2.

KEY_FORMULAS:
  F1 = p_hit*F1_hit + (1-p_hit)*F1_miss
  expected gain = (p_new - p_old)*(F1_hit - F1_miss)
  SE(mean F1, n) ~ sd/sqrt(n)  (sd ~0.3 -> 0.07 at n=20)
  kappa = (p_o - p_e)/(1 - p_e)
